怎麼用

  • 在「貼上資料」把 API 回傳的整段內容貼進去，按解析並匯入。到場、離場兩支 API 分兩次貼即可，系統會累加。
  • 若來源沒有方向欄位（例如只有到場那支 API），把「方向判定」改成整批視為到場再匯入。
  • 去重規則：方向＋日期＋航班號 相同視為同一筆，後匯入的覆蓋舊的，所以同一天重複貼不會灌水。
  • 要累積多天資料做班表，就每天貼一次；跨越的天數愈多，每週班次推估愈準。
  • 資料只存在這個分頁，關掉就沒了。要留存請按匯出資料檔，下次用讀入資料檔接回來。

可辨識的欄位

  • 航班號：FlightNumber、FlightNo、FlightID、班機編號
  • 航空公司：AirlineID、AirlineName、Carrier、航空公司
  • 排定時間：ScheduleArrivalTime、ScheduleDepartureTime、ScheduleTime、ExpectTime、STA、STD、表定時間
  • 實際／預估：ActualArrivalTime、ActualDepartureTime、EstimatedTime、RealTime、ATA、ATD、ETA、ETD
  • 航點：DepartureAirportID（到場的起站）、ArrivalAirportID（離場的目的站）、Airport、起站、目的地
  • 其他：Terminal、Gate、CheckCounter、BaggageClaim、AircraftType、FlightStatus、Remark、FlightDate

時間格式支援 2026-09-09T14:05:00+08:00、2026-09-09 14:05、14:05、1405、202609091405。時間一律當作當地時間，不做時區換算。

統計口徑

  • 準點：實際或預估時間與排定時間相差 15 分鐘以內；延誤：晚於排定 15 分鐘以上。沒有實際時間的航班不計入準點率。
  • 每週班次：該航班在資料中出現過的不同星期幾數量。同一天飛兩班同號航班只算一次。
